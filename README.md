# lampa-tv

Плагин для [Lampa](https://github.com/yumata/lampa): **«Расширенный поиск»** и **«Подборки»**.

- Расширенный поиск по TMDB: жанры (все сразу / любой из), исключение жанров, 54 темы (киберпанк, путешествия во времени, ограбления, по реальным событиям…), годы от–до, рейтинг от, минимум голосов, страна производства, язык оригинала, длительность, сортировка.
- Подборки: Топ-250 IMDb, Топ-100 сериалов IMDb, топы по жанрам и десятилетиям — посчитаны по официальным выгрузкам IMDb (datasets.imdbws.com) взвешенным рейтингом, номера TMDB — через Wikidata.

Подключение в Lampa: Настройки → Расширения → Добавить плагин →
`https://garik9559.github.io/lampa-tv/adv_search.js`

Данные подборок: `imdb_lists.json` (обновляются вручную по свежей выгрузке IMDb).
